## 📌 项目简介

本项目以 **STM32F103C8T6** 为主控芯片，基于 **Keil MDK-5** 开发环境，使用 **STM32 标准外设库（StdPeriph Library）** 编写。系统能够同时采集多种环境参数（温湿度、距离、人体感应、重量、气体浓度），通过 **0.96 寸 SPI 接口 OLED** 屏幕实时显示，并借助 **USB 转 TTL** 模块，实现电脑端通过 **UART 串口** 向 STM32 发送指令，远程控制 **SG90 舵机角度** 与 **LED 灯光开关**。

> **设计目标**：低成本、模块化、易扩展，作为智能家居/实验室环境的监控原型。

| 🔌 **通信** | 串口指令 | USB 转 TTL，电脑端串口助手发送指令控制设备 |

## 🏗️ 系统架构

系统采用**分层模块化**设计，自下而上分为驱动层、功能层和应用层：

```
┌──────────────────────────────────────────────┐
│                应用层 (main.c)                │
│   数据采集调度 · 显示刷新 · 串口指令解析分发   │
├──────────┬────────────┬──────────┬───────────┤
│ 传感器层 │  显示层    │ 控制层   │ 通信层    │
│ DHT11    │  OLED      │ SG90舵机 │ UART      │
│ HC-SR04  │ (SPI)      │ LED      │ (USB-TTL) │
│ HC-SR501 │            │          │           │
│ HX711    │            │          │           │
│ MQ-2     │            │          │           │
├──────────┴────────────┴──────────┴───────────┤
│            STM32 标准外设库驱动层              │
│  GPIO · TIM(PWM/输入捕获) · ADC · SPI · USART │
├──────────────────────────────────────────────┤
│            STM32F103C8T6 硬件层               │
└──────────────────────────────────────────────┘
```

**数据流示意**：
```
传感器采集 → STM32 处理 → OLED 实时显示
                              ↑
电脑串口助手 ──UART──→ STM32 ──→ 舵机 / LED 执行动作
```

## 💻 软件设计

### 开发环境

| 项目 | 版本 / 说明 |
|------|-------------|
| 开发软件 | Keil µVision 5 (MDK-ARM) |
| 固件库 | STM32F10x Standard Peripheral Library v3.5.0 |
| 编译器 | ARMCC (Keil 内置) |
| 烧录方式 | ST-Link V2（SWD 接口）/ 串口 ISP |
| 主控时钟 | 72 MHz（外部 8MHz 晶振 + PLL） |

### 外设资源配置

| 外设 | 用途 | 配置 |
|------|------|------|
| **USART1** | 串口通信 | 波特率 115200，8N1 |
| **SPI1 / SPI2** | OLED 驱动 | 主机模式，8bit，时钟极性低 |
| **TIM4_CH1** | 舵机 PWM | 50Hz（20ms 周期），占空比对应 0~180° |
| **TIM2** | 超声波测距 | 输入捕获测量 Echo 高电平脉宽 |
| **ADC1** | MQ-2 采集 | 12bit，软件触发 |
| **GPIO** | DHT11 / HX711 / LED / 人体感应 | 输入/输出配置 |
